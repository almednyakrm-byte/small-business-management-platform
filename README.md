# منصة إدارة الأعمال التجارية الصغيرة (التسجيل، تتبع المبيعات، التقارير)
==========================

## ملخص المشروع
----------------

منصة إدارة الأعمال التجارية الصغيرة هي تطبيق مفتوح المصدر يهدف إلى تسهيل إدارة الأعمال الصغيرة من خلال تسجيل المبيعات، تتبعها، وإنشاء تقارير مفصلة.

## بنية المشروع
----------------

### مجالات المشروع

* `app`: مجال تطبيق الويب
* `db`: مجال قاعدة البيانات
* `docker`: مجال Docker

### أجهزة المشروع

* `docker-compose.yml`: ملف Docker Compose الرئيسي
* `docker/Dockerfile`: ملف Dockerfile الرئيسي
* `app/requirements.txt`: قائمة متطلبات التطبيق
* `db/schema.sql`: ملف قاعدة البيانات

## إعداد بيئة العمل
-------------------

### إعداد بيئة العمل باستخدام Docker Compose

1. تأكد من أن Docker و Docker Compose مثبتين على جهازك.
2. افتح مجلد المشروع في محرر نصوص.
3. افتح شاشة الأوامر في مجلد المشروع.
4. استخدم الأمر التالي لتشغيل بيئة العمل:
bash
docker-compose up

5. انتظر حتى تتم إقامة البيئة.
6. افتح متصفح الويب ومرر إلى `http://localhost:8000` لفتح تطبيق الويب.
